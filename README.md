# 말랑

내가 자주 쓰는 말을 작은 친구들과 함께 모으는 Windows·macOS 앱입니다.

| 운영체제 | 설치 파일 |
| --- | --- |
| Windows x64 | [Windows 다운로드](https://github.com/6owo9/mallang-releases/releases/download/v0.2.2/Mallang-Setup-0.2.2.exe) |
| macOS 12 이상 · Intel / Apple Silicon | [맥 다운로드](https://github.com/6owo9/mallang-releases/releases/download/v0.2.2/Mallang-0.2.2-mac-universal.dmg) |

[최신 릴리스 전체 보기](https://github.com/6owo9/mallang-releases/releases/latest)

Windows는 EXE를 실행해 설치하고, 맥은 DMG를 열어 말랑을 응용 프로그램으로 복사하세요. 맥 수집에는 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 권한이 필요합니다. 맥의 실제 앱 입력 수집은 시험 단계입니다.

Windows v0.2.0 이상은 앱에서 업데이트 확인 → 다운로드 → 재시작으로 적용할 수 있습니다. 맥은 새 DMG로 교체해 주세요. Windows 설치본은 미서명이며 맥은 Developer ID 서명·공증이 없는 시험 빌드입니다.

원문과 통계는 기기 메모리에서 처리하며 종료 시 초기화됩니다. 입력 내용과 통계를 외부로 보내지 않습니다. GitHub 연결은 업데이트 확인·설치 파일 다운로드에 사용합니다.

이 저장소는 설치 파일과 업데이트 배포용입니다. 모든 앱의 입력 수집을 보장하지 않습니다.
