# 말랑

내가 자주 쓰는 말을 작은 친구들과 함께 모으는 Windows 앱입니다.

**[최신 Windows 설치 파일 다운로드](https://github.com/6owo9/mallang-releases/releases/latest)**

Releases에서 `Mallang-Setup-버전.exe` 파일을 내려받아 설치해 주세요. Windows x64용이며 현재 설치 파일은 코드 서명되지 않았습니다.

v0.2.0부터 앱 아래쪽에서 새 버전을 확인하고 다운로드한 뒤 재시작해서 적용할 수 있습니다. 기존 버전 사용자는 v0.2.0을 한 번 설치해 주세요.

원문과 통계는 기기 메모리에서 처리하며 앱 종료 시 초기화됩니다. 업데이트 확인과 설치 파일 다운로드에는 GitHub 연결을 사용합니다. 입력 내용이나 통계를 업데이트 서버로 보내지 않습니다.

이 저장소는 설치 파일과 업데이트 배포용입니다. 지원 입력창은 앱의 접근성 제공 여부에 따라 다릅니다.
